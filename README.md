## Project Overview

The **Image Processing Virtual Lab** is a web-based project developed to demonstrate different Image Processing practicals through an interactive and user-friendly interface.

The website provides practical demonstrations where users can select sample images or upload their own images and perform different image processing operations using the available controls.

## Project Structure

```text
Mehak_Image_Processing_Systematic/
│
├── index.html
│
└── assets/
    ├── cat.jpg
    ├── puppy.jpg
    ├── golden_puppy.png
    ├── beach.png
    ├── flower.png
    ├── flower_reference.png
    └── animals.jpg
```

## Main File

The complete website functionality is implemented in:

```text
index.html
```

The `index.html` file contains:

* HTML structure of the website
* CSS styling
* JavaScript image-processing logic
* Practical navigation
* Sample image selection
* Image upload functionality
* Execute and Reset controls
* Download functionality
* Output display for practicals

## Assets

The `assets` folder contains the sample images used by the Image Processing practicals.

These images are referenced directly by `index.html`, so the **assets folder must remain in the same project directory as `index.html`**.

## Development Environment

The project was developed and tested using **Visual Studio Code** and **PyCharm**.

The website can be opened directly through `index.html` during development. **Live Server** in VS Code can also be used for convenient local testing.

## Git and GitHub

Git was used to manage the project's source code and maintain different versions of the project.

The project was uploaded to GitHub so that the source code and required assets can be maintained in a remote repository.

The website was deployed using **GitHub Pages**, making the Image Processing Virtual Lab accessible through a web browser.

## How to Run the Website

1. Open the project folder in **VS Code**.
2. Make sure `index.html` and the `assets` folder are present.
3. Open `index.html`.
4. Use **Live Server** in VS Code for local testing, if required.
5. Select the required Image Processing practical from the website.
6. Select a sample image or upload an image.
7. Execute the operation and view the output.

## Important Note

Do not delete, rename, or move the `assets` folder or its images because the website uses these files for sample-image selection and practical demonstrations.

## Deployment

The project is deployed using **GitHub Pages**.

The GitHub repository contains the website source code along with the required assets, allowing the complete Image Processing Virtual Lab to run as a web application.
